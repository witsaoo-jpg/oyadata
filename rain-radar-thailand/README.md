# Rain Radar Thailand on OYA DATA

Public URL: https://www.oyadata.com/rain-radar-thailand/

This folder hosts the OYA DATA-facing shell for Rain Radar Thailand. The application UI is served from the OYA DATA domain, while shared public radar snapshot JSON/images and public overview data are read from the canonical Rain Radar deployment at:

https://witsaoo-jpg.github.io/rain-radar-thailand/

The canonical source project remains:
https://github.com/witsaoo-jpg/rain-radar-thailand

This avoids running duplicate TMD snapshot jobs while preserving the OYA DATA URL and scoped PWA installation.
